# gold-solucoes

Official static website for Gold Solucoes, serving Palmas and Tocantins.

## Files

- `index.html`: page content, styles, and browser scripts.
- `assets/`: project photos, logo, and the locally hosted Inter font.
- `vercel.json`: static hosting configuration and response headers.

No package installation or build step is required. Open `index.html` in a browser
to preview the site locally.

## Deployment

Production: https://gold-solucoes.vercel.app/

Vercel project: `gold-solucoes`. Local Vercel configuration and environment files
are excluded from version control.
